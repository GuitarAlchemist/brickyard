Delta's window becomes a hall you can walk through, with an office where each Claude Code session is a robot, and
Delta hears one copy of a sentence that two microphones in one room both heard. 0.7.1 is the first release of this
work: 0.7.0 was tagged but never published, as its build failed.

```
/plugin marketplace add GuitarAlchemist/brickyard
/plugin install delta@brickyard
/delta:setup
```

If Delta is already installed, update the marketplace and the plugin, then run `/delta:setup` again to install this
version: it keeps your language and the copies it recorded.

```
claude plugin marketplace update brickyard
claude plugin update delta@brickyard
```

## What changed

- **Of two copies of a sentence, the louder goes.** When the headset and a phone in the same room both send a
  sentence within 1.5 s, and the two share a word, Delta keeps the louder copy and drops the other, however Whisper
  wrote each. The rule was set from six pairs heard live with 0.6.0; it is not yet heard live with two microphones.
- **Languages and the microphone, from the window.** A button goes through French, both and English, and Delta also
  changes its languages when asked aloud. Another mutes the computer's microphone, with a meter that shows how loud
  the voice is.
- **Captions.** The caption shows what you are saying while you say it, and each sentence Delta says as it says it.
  T hides what was said in the room without « Delta », for a window that is shared.
- **Claude thinking.** A small beating brain shows while Claude works on an answer, with how long it has worked.
- **A hall to walk through.** The camera walks the hall, frames a view, flies a cinematic and turns with the wheel.
  The agents' office shows one robot per Claude Code session that wmux reports, and a wall screen shows a session,
  Pong or an arcade game. The clocks of Ottawa and Paris hang on the wall. A click on the arcade cabinet plays
  PARSEC, a third party's game: only then does Delta fetch it from parsec.games.bu.app.
- **The IX workshop.** A knot that IX computed turns on a stand, and the knots' floor shows a gallery of knots, each
  read and named by IX, when IX is installed.
- **RTX.** On an RTX GPU the hall's shadows and occlusion are traced by rays. F9 path-traces the hall, F6 turns every
  setting up, and F10 shows what the GPU offers and what the scene uses. DLSS Ray Reconstruction and frame generation
  are used only when NVIDIA's signed Streamline DLLs are put in `%LOCALAPPDATA%\delta\streamline` by hand: the release
  does not ship them, and NVIDIA's updater then contacts NVIDIA.
- **Pairing.** Opening the pairing card with no live code asks the gateway for a new one, and a window started later
  gets the code still alive. The Inviter button shows an invitation's QR code and copies its link.
- **The window.** Delta's face is its icon, its corner shows its version, and a click on the version shows these
  notes. Esc no longer closes it, and it keeps drawing while it is dragged.
- **The ears.** whisper-server's routes sit under a path only the brain knows, kept out of errors and the journal.

Still without the camera's hands.

Windows 10 or 11 x64 only, with a Vulkan 1.3 GPU and a microphone.
