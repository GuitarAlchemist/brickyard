Delta's own short commands, its local triage and its shelf now speak English as well as French.

```
/plugin marketplace add GuitarAlchemist/brickyard
/plugin install delta@brickyard
/delta:setup
```

`/delta:setup` asks which language Delta should hear and speak, English by default or French. If Delta is already
installed, run `/delta:setup` again to install this version: it keeps your language and the copies it recorded.

## What changed

- **Delta obeys short commands in either language, whatever its own.**
  - Its window: "Delta, move to the top left", "minimize", "full screen", "hide", "Delta, come back".
  - Its shelf: "Delta, show me the sessions", "go down", "open", "back", "close the menu".
  - It answers in its own language, and the shelf's labels follow that language.
- The optional local triage sorts English as well as French, and answers small talk in Delta's language.
- While Claude Code compacts its context, Delta says so in its own language.
- The English voice reads "IX" as "I X".

Windows 10 or 11 x64 only, with a Vulkan 1.3 GPU and a microphone.
