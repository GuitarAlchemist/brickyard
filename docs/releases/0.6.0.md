Delta keeps listening while you talk to it and shows it, pairs a phone from its window, and speaks once per room: on the
device that asked.

```
/plugin marketplace add GuitarAlchemist/brickyard
/plugin install delta@brickyard
/delta:setup
```

If Delta is already installed, update the marketplace and the plugin, then run `/delta:setup` again to install this
version: it keeps your language and the copies it recorded.

```
claude plugin marketplace update brickyard
claude plugin update delta@brickyard
```

## What changed

- **A conversation lasts while it goes on, and shows it.** After « Delta », each sentence for Delta and each of its
  answers keep the conversation open 30 seconds more, where before the next sentences had 15 seconds and an answer 20.
  In the bottom left corner of the window, « Je t'écoute » and a ring of green dots that go out one by one show it
  until Delta needs its name again. A sentence for someone else still ends the conversation at once.
- **Pair a phone from the window.** The phone icon in the top right corner opens, on a click or with P, the QR code of
  the link a phone opens to pair with a gateway such as IX's, for as long as its code lives, then says that it
  expired. The code is a credential while it lives: the card shows only when you ask, and the link is written to no
  log or journal. The brain draws the code itself.
- **One room, two devices.** An answer to a sentence spoken on the phone plays on the phone alone, rather than on the
  computer too, a moment apart, with a gateway that says it plays the answers to its own sentences
  (`X-Delta-Plays: own`); with any other, the computer plays them as before. A sentence the other device sent
  in the same words a few seconds before is dropped, but the two microphones of one room seldom write the same words:
  see the known problems in NOTES.
- **Every sentence of an answer names its question.** In 0.5.0 only the first sentence of an answer carried its
  `utterance_id` on `/said`.
- **Whisper's loops.** A sentence Whisper writes three times in a row or more, as it can over a long silence, is heard
  once.

Windows 10 or 11 x64 only, with a Vulkan 1.3 GPU and a microphone.
