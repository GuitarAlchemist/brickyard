Delta can now be Claude Code's voice. Install it as a plugin, then talk to your Claude Code session aloud, in French.

```
/plugin marketplace add GuitarAlchemist/brickyard
/plugin install delta@brickyard
/delta:setup
```

`/delta:setup` asks before downloading anything: about 700 MB the first time. It downloads this release, Piper and a
French voice, whisper.cpp and a Whisper model, and checks each against its SHA-256. It uses the copies you already
have if you name them.

There are then two ways to talk:

- **Your voice comes in by itself.** Restart Claude Code with
  `claude --dangerously-load-development-channels plugin:delta@brickyard`, and start your sentences with "Delta" or
  "Claude". Channels are a research preview.
- **In any session.** Run `/delta:talk`.

## What changed

- `brain.exe -mcp` is an MCP server with four tools, `say`, `listen`, `window` and `shelf`, and a Claude Code channel.
- Through the channel, Delta passes on:
  - sentences that start by calling it, "Delta, …", or its brain, "Claude, …";
  - the next sentences within 15 seconds;
  - your answer within 20 seconds of its last words.

  It drops « je ne te parle pas », and sentences that first call one of the author's other sessions.
- Each answer carries the id of the sentence it answers. `-journal <file>` writes one line per sentence heard, with
  where it went and why, and one per sentence said.
- With Claude Code, Ollama is not needed: Claude answers. With `-triage <model>`, a small local model sorts what Delta
  hears first. It answers greetings and thanks itself, drops what is meant for someone else, and passes the rest to
  Claude. A lamp on Delta's chest is green while the small model answers and gold while Claude does.
- Delta's torso shows how full Claude's context is, and when Claude Code compacts it, through the plugin's hooks.
- Delta's face takes expressions. Delta moves, sizes and hides its own window. A shelf in its window lists this
  computer's Claude Code sessions and the installed plugins.
- Delta speaks through a warm effect on the same Piper voice: an equaliser, a compressor, a touch of saturation and a
  small room. `-fx none` gives Piper's own voice.
- One Delta runs at a time: a newer brain takes over from the older one.
- `POST /gesture` takes hand gestures from a camera process. No camera process ships yet.
- The ears and the voice run without console windows, and stop with the brain.
- CI checks the brain, the scene, the plugin and the marketplace. A tag publishes the release.

The standalone mode still runs with `start-delta.ps1` and Ollama.

Windows 10 or 11 x64 only, with a Vulkan 1.3 GPU and a microphone.
