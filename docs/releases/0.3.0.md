Delta now hears and speaks English as well as French. English is the default.

```
/plugin marketplace add GuitarAlchemist/brickyard
/plugin install delta@brickyard
/delta:setup
```

`/delta:setup` asks which language Delta should hear and speak, then asks before downloading anything: about 700 MB
the first time. It downloads this release, Piper and a voice for that language, whisper.cpp and a Whisper model, and
checks each against its SHA-256. It uses the copies you already have if you name them.

There are then two ways to talk:

- **Your voice comes in by itself.** Restart Claude Code with
  `claude --dangerously-load-development-channels plugin:delta@brickyard`, and start your sentences with "Delta" or
  "Claude". Channels are a research preview.
- **In any session.** Run `/delta:talk`.

## What changed

- **Delta hears and speaks English or French.**
  - `/delta:setup` asks which, and records it in `delta.json` as `"language"`.
  - It installs the voice for that language: en_US-ljspeech-medium (its dataset, LJ Speech, is public domain) or
    fr_FR-siwis-medium.
  - Run `/delta:setup` again to switch. A 0.2.0 install keeps French.
- Whisper transcribes the chosen language, and Claude is told to answer in it.
- **Delta's addressing rules understand English.**
  - "Hey Delta, …" calls Delta, "I'm not talking to you" is dropped, and "I was talking to Codex" goes to Codex.
  - Whisper often writes an English "Delta" as "Delter", which now counts as Delta.
- Whisper's English inventions over silence, such as "Thanks for watching", are dropped like the French ones.
- Running `/delta:setup` again reuses the copies it recorded, instead of offering to download them again.
- The standalone mode takes `-Lang fr`; English is its default too.
- The README has a French version, [README.fr.md](https://github.com/GuitarAlchemist/brickyard/blob/main/README.fr.md).

**Still in French only:**
- the short commands Delta obeys by itself, to move its window or open its shelf;
- the optional local triage;
- what Delta says while Claude Code compacts.

In English, ask Claude instead: it does the same with Delta's `window` and `shelf` tools.

Windows 10 or 11 x64 only, with a Vulkan 1.3 GPU and a microphone.
